# 狗头军师 · iOS 键盘预览版

将狗头军师放进 iPhone 的聊天键盘：日常输入中文拼音、英文、数字与符号；需要建议时点“军师”，复制消息，核对原文和对象，分析后选择候选填入草稿，最后自己发送。主 App 提供接口配置、截图识别、关系资料、详细分析和关系趋势 K 线。

本版基于 [Jev iOS](https://github.com/jev-chat/jev-chat-jarvis-ios) 的键盘扩展方案开发，融合本仓库的关系判断和自然表达指南。配色使用米白、暖橙与柴犬标识。最低系统 iOS 16，当前提供 **Xcode 源码工程**；主 App 与键盘扩展均已编译通过，并已在个人 iPhone 完成签名安装与主 App 启动。键盘与宿主聊天 App 的完整交互仍需真机验收，暂无公开可安装的签名 IPA、TestFlight 或 App Store 下载。

- 填入确认和候选理由使用键盘内页面，避免系统弹窗使键盘退出；填入后回到本键盘的打字布局。

## 功能与入口

| 入口 | 内容 |
| --- | --- |
| 键盘 → 打字 | 中文全拼、横向候选选字、连续拼音分词，英文大小写、数字、符号、常用表情、删除、空格、换行与光标移动；全部本地处理 |
| 键盘 → 读取剪贴板 | 只在点击时读取已复制的消息；核对说话人、当前对象和原文后分析 |
| 键盘 → 识图 / 截图识别 | 等待系统快捷指令截图，按设置使用 Apple Vision、DeepSeek 或 OpenRouter；云端先预览并确认上传。也可读取已复制截图，另有系统捕获实验入口 |
| 键盘 → 读取输入框里的草稿 | 读取光标前系统提供的局部草稿文字，无法取得完整聊天历史 |
| 键盘 → 候选回复排序 | 1–3 条候选、相对推荐权重、理由与代价；可复制或确认后填入当前光标 |
| 键盘 → 更像我一点 | 仅参考当前已核对原文中标为“我”的句子，保留已接受的分析与策略 |
| 键盘 / 主 App → 详细分析 | 可能意图、判断把握、自己的感受、事实、推测、未知、下一步与停止条件 |
| 主 App → 配置 | 图形化填写 DeepSeek、OpenRouter、Jev Key，选择判断、回复、识图模型及回复偏好 |
| 主 App → 关系 | 七种关系阶段、六种目标、有限背景；主动保存后可在键盘切换对象 |
| 主 App → 使用 → 从截图读取聊天 | 相册选择聊天截图、从文件选图、粘贴截图；显示本轮图片预览与 OCR 原文 |
| 主 App → 设置一键截屏识别 | 创建“截屏 → 截图交给键盘（按配置）”快捷指令，可绑定辅助触控或轻点背面；也可选“识别聊天截图（按配置）”在主 App 核对 |
| 主 App → K 线 | 五组走势示例或聊天 CSV 导入，在本机按每日消息净差绘制 |

键盘默认进入“打字”；顶部“打字 / 军师”切换普通输入与分析面板，地球键可切回自己的其他输入法。字母按键固定在独立区域，候选栏横向滚动；空格键加宽，横屏自动压缩高度。跨 App 截屏需用户确认系统捕获，或主动触发系统快捷指令；不扫描聊天数据库，不替你发送消息。“换行”只插入换行字符。聊天 App 可能禁用第三方键盘；密码框、部分电话输入框也会使用系统键盘，实际兼容性需逐个 App 验证。

## 本地输入法

中文使用基础全拼：输入 nihao，在候选栏选“你好”，或按空格确认首选。连续拼音可分词转换；点“分词”插入拼音分隔符，例如 xi'an。候选栏可左右滑动，选一个前缀词后可继续处理剩余拼音。待输入拼音显示在键盘上，选择候选后才写入宿主输入框；删除键优先删除待输入拼音，长按可连续删除。

底部“中”或“英”键切换语言；英文模式支持大小写。“123”打开数字，“#+=”打开符号，“ABC”返回字母。关闭完全访问仍可本地打字，联网军师需要完全访问。日常输入不调用模型，不保存输入历史或学习词库。

离线词库包含 65,125 条词条，来源为 [Rime 袖珍简化字拼音](https://github.com/rime/rime-pinyin-simp)，按 Apache-2.0 保留词库、原作者说明、许可证和版本记录；键盘包内包含许可证。使用本项目的轻量分词与候选排序实现，尚未提供九宫格、语音输入、个人词频学习或成熟输入法的纠错能力。

## 编译与安装

需要完整 Xcode（15 或更新版本）、iOS SDK，以及能为 App Groups 和 Keychain Sharing 配置签名的 Apple 开发者团队。只有 Command Line Tools 无法编译此 App。

1. 用 Xcode 打开 [GoutouJunshi.xcodeproj](GoutouJunshi.xcodeproj/project.pbxproj) 所在的工程。
2. 修改 [Signing.xcconfig](Signing.xcconfig)：填写自己的 Team ID；将 App Bundle ID 与 App Group 改为自己团队可用的唯一标识。例如 App ID 为你自己的反向域名，键盘 ID 会自动追加 .keyboard。
3. 在 GoutouJunshi 和 GoutouKeyboard 两个 target 的 Signing & Capabilities 中确认相同 Team、相同 App Group、相同 Keychain Sharing group。共享钥匙串默认使用 AppIdentifierPrefix 加 App Bundle ID。需在开发者账户中启用相应能力和更新描述文件；不要把两个 target 配成不同的共享组。
4. 选择 GoutouJunshi scheme，先运行 iPhone 模拟器检查主 App，再连接 iPhone 签名运行。按 Xcode 与手机提示开启开发者模式。分发需另行完成有效签名和 Apple 审核流程。
5. 安装后打开主 App → 配置，填写 Key，点“保存并应用配置”。填写内容直接进入本机共享钥匙串，无需编辑配置文件。
6. 到 iPhone“设置 → 通用 → 键盘 → 键盘 → 添加新键盘”添加“狗头军师”。打开聊天输入框，用地球键切换到狗头军师，即可本地打字；使用联网军师时再开启“允许完全访问”。

普通 Apple 账号可在 Xcode 使用 Personal Team 为自己的设备调试安装，描述文件有效期为 7 天，过期需重新编译安装；本项目的共享组签名与键盘行为仍需真机验证。通过 TestFlight 分发需发布方加入 Apple Developer Program，外部测试首个版本需通过测试审核，测试者无需开发者会员。参见 [Apple 账号说明](https://developer.apple.com/help/account/basics/about-your-developer-account)与 [TestFlight 说明](https://developer.apple.com/testflight/)。

完全访问用于键盘联网和与主 App 共享配置。App 会显示该权限的用途；仅在主动核对并分析时提交原文。主 App 中的“最近已连接”是上次键盘连接状态，当前权限仍以键盘实际检查为准。Apple 的键盘限制见[官方文档](https://developer.apple.com/library/archive/documentation/General/Conceptual/ExtensibilityPG/CustomKeyboard.html)。

主 App、键盘与捕获扩展使用同一 App Group；捕获扩展不需要共享钥匙串。共享配置错误会显示“App Group 未连接”，不会改用不共享的配置静默继续。已保存 Key 不回显；密钥框留空表示保留，可按服务单独删除。若签名变化导致共享钥匙串不可访问，需要修正签名后重新保存自己的 Key。

## 只用 DeepSeek

在主 App → 配置点击“判断＋回复均使用 DeepSeek”，填写自己的 DeepSeek Key 与账户支持的模型 ID。默认模型 ID 与本项目其他平台一致，为 deepseek-flash，可按服务商实际开放情况修改。点“测试 DeepSeek”后“保存并应用配置”。

- **策略判断：DeepSeek。** 先整理事实和边界，再对承接、降压、调侃、轻推、约见、澄清、收线七种策略做三次标签轮换，检查首个输出 token 的 logprobs。全七类齐全、三轮胜出一致且与证据判断一致时，显示相对策略权重；不满足时标为权重不可用，保留 DeepSeek 的证据判断。明确停止联系时跳过权重请求，约束为收线且不生成推进候选。
- **回复生成：DeepSeek。** 按接受的策略和关系目标生成分析与候选，再独立评分排序；格式错误、截断或策略冲突会提示失败。排序失败时保留候选并标为权重不可用。
- **截图识别：Apple Vision · 本地** 可减少截图上传。改为 DeepSeek 图片识别时，需要该模型支持图片输入；每张截图会先征求发送确认。

一次正常的多候选 DeepSeek 分析通常需要六次请求：证据一次、标签判断三次、生成一次、排序一次。证据格式可修复一次；权重不可用会提前结束权重检查，单候选无需额外排序。连接测试和分析均消耗自己账户的接口用量，不包含赠送额度。

## Jev 与 OpenRouter

策略判断可单独改成 TypeSafe Jev，填写 Jev Key 和模型 ID。Jev 使用官方 systemone 接口，判断失败会显示原因；不会偷偷切换到其他服务。

回复生成可选择 OpenRouter，填写其 Key 和回复模型 ID；可与 DeepSeek 策略判断组合。识图另有独立的 OpenRouter 识图模型 ID，需要支持图片输入。OpenRouter 在本版用于回复与识图，策略判断可选 DeepSeek 或 Jev。官方接口地址固定，避免把某个服务的 Key 发到另一服务。

“测试连接”使用当前填写值，不必先保存；成功只代表该测试请求通过。真实分析需要结构化输出，图片识别还需视觉能力；模型能力、免费额度与限额以服务商为准。

## 一轮实际使用

**从截图开始：**在聊天中截屏，打开狗头军师主 App → 使用 → 从截图读取聊天 → 选择聊天截图。也可从文件选择，或拷贝图片后点“粘贴截图”。图片预览与识别文字会显示在页面中；核对后确认分析，再把本轮结果交给键盘。

**在键盘中识图：**切换狗头军师键盘，点顶部“识图” / 军师中的“截图识别”，准备接收系统快捷指令截屏的文字。快捷指令与实验捕获入口见下方说明。已有截图可在照片中打开 → 分享 → 拷贝照片，再在键盘点“读取已复制的截图”。本地模式点“识别聊天文字”；云端模式需点“发送截图并识别”，显示所选服务及接口用量。需要键盘完全访问。

识别结果先进入核对页，不自动分析。左右气泡仅用于初步归属，居中标题等可能标成“说话人待确认”；点击键盘核对页的一行，可改为“我 / 对方”或忽略非聊天文字。需改错字时，“复制原文供核对”可把内容带到主 App 编辑。截图被缩小重新编码，图片只在内存，不另存原始截图。

在聊天中长按对方消息复制，切换狗头军师键盘，点顶部“军师”，再点击“读取剪贴板”。单条可切换“本条是对方说的 / 本条是我说的”；多轮内容需逐条核对。确认对象、原文与双方身份，再点“确认并分析”。

结果先显示可能意图与军师建议，再展示“候选回复排序”。点击“为什么这样回”看适用理由与代价；详细页展开事实、推测、未知、下一步和停止条件。“更像我一点”仅修改候选口吻。

填入前在键盘面板内再次确认当前收件人与候选文字；确认页不会打开系统弹窗。填入后回到狗头军师自己的“打字”布局，可继续修改；本轮分析保留，点“军师”可再查看。键盘只能把文字写到当前输入光标处，无法自动核实微信或 Soul 里是谁；切换会话后必须手动选对象并重新核对。已有草稿会保留，候选会追加，发送需要你点击聊天 App 的按钮。确认仅当前键盘可见、对象和配置不变时有效，60 秒后失效，重复点击不会重复填入。

需要更长的聊天背景时，打开主 App，在“使用”中粘贴多轮原文，或从相册 / 文件选截图。修正识别内容，使用“我：”“对方：”逐条标注，再确认分析。“把本轮结果交给键盘”会主动暂存这一轮，切回聊天即可在键盘取用；有效期 5 分钟，只能取用一次。修改原文、对象或接口配置会清除旧交接。

## 一键截屏识别

### 键盘内系统捕获（实验）

在聊天输入框切换到狗头军师键盘 → 点顶部“识图” → “屏幕捕获（实验）” → 点系统圆形捕获按钮 → 在 iOS 面板确认“开始直播”。该入口使用 ReplayKit 的系统屏幕捕获服务；界面名称由 iOS 决定。GoutouCapture 扩展只处理一帧，裁掉底部键盘区域，按配置返回本地识别文字或待确认的云端识图截图，随后自动停止。此扩展不包含联网客户端，不读取 API Key，不处理音频。系统可能显示一次结束提示；云端模式回键盘预览并点“发送截图并识别”，本地模式直接核对文字，再确认分析。

捕获请求 90 秒有效；超时可点“重新等待截图”。回传文字最多 12000 字，临时存入排除备份的共享文件，5 分钟内只能取用一次。云端模式的待确认 JPEG 最多 4 MB、暂存 5 分钟，识别成功、取消、切换对象或修改配置时删除；不会自动上传。到期数据在下次访问时删除。不会自动分析或填入聊天。

当前入口面向 **iOS 16–26**，依赖键盘完全访问与用户逐次系统确认。Apple 在 iOS 27 SDK 将该 ReplayKit 广播接口标为不再支持，iOS 27 界面显示快捷指令 / 复制截图方案。编译通过不能证明聊天 App 内捕获可用，真机系统确认、取帧与回到键盘仍需验收。系统受保护画面可能无法采集。参见 [Apple ReplayKit 安全机制](https://support.apple.com/guide/security/replaykit-security-seca5fc039dd/web)。

### 系统截屏后，文字直接回键盘

主 App → 使用 → “设置一键截屏识别”提供设置说明。键盘顶部“识图”只是进入等待页，无法直接触发其他 App 的系统截屏。真正的截图由系统快捷指令完成。

1. 在系统“快捷指令”创建或编辑“截图问军师”。
2. 第一项使用系统“截屏”，第二项使用狗头军师的 **“截图交给键盘（按配置）”**。已有“截图交给键盘（本地）”动作会沿用新配置，无需重建。
3. “聊天截图”接收上一项的截屏结果；不添加“打开 App”或拷贝操作。
4. 在“设置 → 辅助功能 → 触控 → 辅助触控 → 自定操作”把轻点两下绑定到这个快捷指令，也可绑定轻点背面。
5. 在聊天页切换到狗头军师键盘，点“识图”，90 秒内双击系统悬浮球。选 Apple Vision 时文字直接回到核对页；选 DeepSeek / OpenRouter 时截图回到预览，点“发送截图并识别”后调用所选服务。不打开主 App。

收起键盘不会取消等待，也不会清空已经识别的原文和分析结果。重新点击聊天输入框并切回狗头军师键盘，会恢复最近一轮；原文与结果在本机暂存 5 分钟，重新打开不延长有效期。恢复后仍需核对双方身份与当前收件人；不会自动分析或填入。点击“清空本轮”可立即删除，切换对象或修改配置会清除旧轮次。

截图会排除底部键盘区域，因此只能读取键盘上方可见的聊天。OCR 严格沿用配置：Apple Vision 在本机运行；DeepSeek 使用配置的 DeepSeek 模型与 Key；OpenRouter 使用独立的图片模型 ID 与 Key，均须支持图片输入。云端识图失败会显示真实错误，不自动回退本地。原文与说话人必须人工核对，模型分析仍需主动确认。待上传截图通过短时 App Group 文件保留预览，最多 4 MB、5 分钟，识别成功或取消后删除；本地模式仅传递文字，最多 12000 字。修改对象或配置会取消等待；错过 90 秒需点“重新等待截图”。快捷指令首次运行可能需要系统确认。

**“识别聊天截图（按配置）”** 用于主 App 核对。它会打开主 App，本地模式直接识别，云端模式先确认上传。旧“识别聊天截图（本地）”沿用同一动作身份和新配置；如需回键盘，请换成“截图交给键盘”。后台动作的真机系统执行、宿主聊天应用中的键盘接收仍需实际验收。

## 怎样理解百分比

- **意图判断把握**：模型对推测的自评，缺乏事实时应为空。
- **策略权重**：Jev 返回的策略分布，或通过检查的 DeepSeek 首 token 相对权重；详情标明来源。
- **候选权重**：回复模型对当前候选打相对推荐分，再归一化成合计 100% 的排序权重。只有一条时显示 100%，只表示当前候选集合中的占比。

这些数字未经过统计校准，不代表对方真实意图的已验证概率、回复率或关系成功率。离线示例中的数字用于展示。

## K 线与 CSV

主 App → K 线中可选择双向升温、热聊后降温、冲突后修复、忙但仍兑现、明确边界后收线。示例来自本仓库的虚构聊天案例。

导入 CSV 要求 UTF-8、时间升序，以及 timestamp、sender、message 三列；sender 为 me / other，可附加 event 列。最多 4 MB、20,000 条消息，支持引号、逗号、多行文字。示例格式：

    timestamp,sender,message,event
    2026-08-01 10:00:00,me,周六看展吗,提出邀约
    2026-08-01 10:01:00,other,我先看下安排,

每条我方消息记 -1、对方消息记 +1；按天形成累计消息净差的开高低收，金色点标记事件。日期无时区时按所填日期分组；ISO 8601 带时区的时间统一转 UTC 分组。图表显示最近 180 个有消息的日期。CSV 原文仅用于本机计算，不发到接口、不保存成关系档案；K 线无法从一次截图还原完整历史，也不衡量爱意或关系质量。

## 本地数据

Key 保存在两个 target 共用的本机 Keychain 条目中。当前对象与偏好保存到 App Group 的 UserDefaults；只有主动勾选档案保存时，才加入可切换的对象列表，最多 100 个，不保存聊天全文。

主 App 原文与结果默认留在进程内存；主动交给键盘或触发识图回传才写入共享交接文件，取用后删除。键盘另在排除系统备份的本机文件暂存最近一轮原文和结果，以支持收起后恢复；该轮次文件不保存截图、拼音输入或确认状态。云端 OCR 的待确认截图使用独立短时交接文件，最多 4 MB、5 分钟，启用系统文件保护并排除备份，识别成功或取消后删除。暂存 5 分钟后失效，下一次访问时删除；重新打开不刷新有效期，iOS 不保证后台到点删除。可在键盘“清空本轮”或配置页立即清除暂存、交接和本轮，或删除各服务 Key；关系页可删除对象资料。钥匙串项目在卸载后可能保留，需在卸载前主动删除不需要的 Key。

本项目没有埋点或自己的中转服务器。模型请求直接发至所选服务；取消操作会停止后续步骤并丢弃过期结果，已发出的请求无法撤回。完整说明见仓库 [PRIVACY.md](../../PRIVACY.md)。
