# 狗头军师 Jev Chat · Windows 本地启动与实机测试指南

> 适用本机克隆：`D:\goutoujunshi`（wstaery/goutoujunshi-jev-chat-addQQ，QQNT 适配版）
> 更新：2026-10-13

## 一、运行环境（已就绪）

- 系统 Python 3.10 + 全部依赖已装在 `integrations\jev_windows\.venv`
- 依赖要求 Python 3.10–3.12（RapidOCR 1.4 不支持 3.13+）
- 密钥、`config.json` 都在本机，不入 Git

## 二、启动方法

```powershell
cd D:\goutoujunshi\integrations\jev_windows
.venv\Scripts\python.exe main.py
```

- **退出**：点悬浮窗标题栏右侧的「关闭助手」即可整体退出
- **重建环境**（仅换电脑或环境损坏时需要）：

```powershell
cd D:\goutoujunshi\integrations\jev_windows
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
# 国内网络慢时加镜像：-i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 三、界面速览

- 悬浮窗标题栏：**采集开关**、设置、「K 线」、「最小化」、「关闭助手」
- 主区：「核对原文并分析」（人工核对后才会调模型）、候选卡片（复制 / **填入草稿** / 为什么这样回）、「详细分析」、「更像我一点」
- 设置页关键项：
  1. **目标聊天应用：微信 / QQ**（本次新增，切换后采集自动重启）
  2. 关系背景、说话风格、参考上下文（可先用默认）
  3. 模型密钥：想做完整分析需要配「策略判断」（Jev 或 DeepSeek）+「起草」（DeepSeek / OpenRouter 等）；识图默认本地 RapidOCR，不用配
  4. 点「保存设置」生效

## 四、QQ 实机验收清单

准备：打开 QQ 主面板并保持窗口可见（收进托盘不行；最小化会自动还原）；打开任意会话，建议先用「我的电脑」不打扰别人。

1. 设置 → 目标聊天应用 → **QQ** → 保存设置
2. 打开标题栏「**采集**」开关；在 QQ 里发几条消息（自己发也行，点「核对原文并分析」看「我」的判定）
3. 核对页：检查识别文字与「我 / 对方」→ 确认后出候选
4. 试「填入草稿」→ 到 QQ 输入框检查 → **发不发永远自己决定**
5. 切回微信重复一遍（回归验证）

验收打勾：

- [ ] QQ 收托盘时状态栏提示未找到 QQ 窗口；打开面板后能开始采集
- [ ] 拖动 QQ 窗口大小/位置后识别不跑偏
- [ ] 双方交替发言，「我 / 对方」判定正确（金黄色主题气泡也要对）
- [ ] 群里开「群聊指定回复对象」选人后，候选面向所选对象
- [ ] 填入后文字在输入框且未发送；输入框已有文字时再填一次，应追加在末尾
- [ ] 切换 微信 ↔ QQ 后两边都能正常采集
- [ ] 微信路径与以前行为一致（无回归）

## 五、已知限制（V1）

- QQ 仅支持**主面板内嵌**聊天；独立聊天窗口不支持
- 浅色皮肤已按此机器标定；深色主题尽力兼容；显示缩放以 100% 为标定基准
- QQ 会话列表宽度被拖得与默认差异很大时，识别区可能偏移（默认宽度已适配）
- 微信路径代码与旧版等价，但本机尚未实机复测

## 六、排障

| 现象 | 处理 |
| --- | --- |
| 「未找到 QQ 的可见窗口」 | 从托盘打开 QQ 主面板再试 |
| 「消息区认不出来（窗口太小？）」 | 拉大窗口、等界面铺好 |
| 识别文字不对 / 区域画歪 | 设置里开「调试视图」，实时看识别框 |
| 填入没反应 | 确认没切换会话、窗口没被遮挡、前台是目标应用 |
| 卡住或报错 | 关掉重开；把复现步骤和界面「聊天记录」里的报错发我 |
